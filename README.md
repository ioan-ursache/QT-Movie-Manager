## Object-Oriented Programming Application Project

*The following application is a mock-up project of a movie management system coded in C++, with its UI provided by the Qt framework.*

- This program has been created as a Visual Studio solution. 
- Data is persistent, the program accepting both CSV and JSON formats. 
- Basic CRUD operations are ensured for movie objects.
- There are additional Undo/Redo and Filtering features.
- Manual tests are included.
